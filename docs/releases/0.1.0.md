# Mirante 0.1.0

Mirante 0.1.0 is the first public release of the extensible Web GIS client for
GeoNode. It provides a functional deployment baseline while the public SDK and
compatibility contract continue to evolve under Semantic Versioning 0.x.

## Highlights

- Session authentication and capability-based authorization with vanilla
  GeoNode 5.1.0.
- Dataset catalogue, GeoJSON, KML, and zipped Shapefile ingestion, optional
  metadata, styling, visibility, and upload progress.
- WMS visualization, feature inspection, layer fitting, attribute tables,
  infinite scrolling, typed filters, highlighting, and CSV or GeoJSON export.
- GeoNode map search, creation, update, restoration, and persisted filters.
- Extensible tools, login providers, locales, base maps, visual identity, and
  permission-aware features through public configuration and SDK contracts.
- Hardened production container and a complete Docker Compose deployment with
  GeoNode, GeoServer, Celery, PostgreSQL/PostGIS, Redis, and Memcached.

## Container image

The release workflow publishes the same version for `linux/amd64` and
`linux/arm64` with an SPDX SBOM and build-provenance attestation:

```text
ghcr.io/barbosaneto/mirante:0.1.0
```

Use the complete `0.1.0` tag in production. Do not deploy the mutable `0.1` or
`latest` tags.

## Compatibility and limitations

- GeoNode 5.1.0 is the supported upstream target for this release. Other
  versions have not been certified.
- Mirante 0.x public contracts may change between minor releases with documented
  migration guidance.
- Browser automation and a formal evergreen-browser matrix are not yet part of
  the release gate.
- Operators remain responsible for public TLS, backups, monitoring, secret
  management, GeoNode permissions, and infrastructure hardening described in
  the production documentation.

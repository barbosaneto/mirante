# Mirante 0.1.1

Mirante 0.1.1 completes the binary distribution of the production stack. A
server no longer needs the source repository, Node.js, build tools, or a local
image build.

## Deployment fix

The GitHub Release provides five deployment assets:

- `compose.yml`: complete Mirante and vanilla GeoNode stack without `build:`.
- `compose.arm64.yml`: native ARM64 overrides for unsupported upstream images.
- `mirante.env.example`: documented production environment template.
- `validate-environment.sh`: configuration preflight.
- `SHA256SUMS`: checksums for the four deployment files.

AMD64 deployments consume the official GeoNode, GeoServer, PostGIS, Redis, and
Memcached images directly. The GeoNode project does not publish ARM64 images
for GeoNode, its Nginx proxy, GeoServer, or PostGIS, so the ARM64 override uses
four narrowly scoped native compatibility images from the public Mirante GHCR
package. Redis and Memcached remain official upstream images on both platforms.

## Installation

Download the assets from the
[Mirante 0.1.1 release](https://github.com/barbosaneto/mirante/releases/tag/v0.1.1),
verify them, copy `mirante.env.example` to `.env`, replace every placeholder,
and run:

```bash
sh ./validate-environment.sh .env compose.yml
docker compose --env-file .env -f compose.yml pull
docker compose --env-file .env -f compose.yml up -d --wait --wait-timeout 900
```

On ARM64, add the architecture override to validation and every Compose
command:

```bash
sh ./validate-environment.sh .env compose.yml compose.arm64.yml
docker compose --env-file .env -f compose.yml -f compose.arm64.yml pull
docker compose --env-file .env -f compose.yml -f compose.arm64.yml up -d --wait --wait-timeout 900
```

For subsequent Mirante-only updates, change `MIRANTE_VERSION` in `.env`, then
pull and recreate only the `mirante` service. The pinned GeoNode, GeoServer,
PostgreSQL, Redis, Memcached, and internal Nginx images remain unchanged unless
a later release explicitly requires a stack migration.

[production guide](https://github.com/barbosaneto/mirante/blob/v0.1.1/docs/deployment.md),
[environment reference](https://github.com/barbosaneto/mirante/blob/v0.1.1/docs/environment.md),

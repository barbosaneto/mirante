# Support

Mirante is experimental community software and is provided without warranty or
a support-level agreement.

## Where to ask

- Use a GitHub issue for a reproducible Mirante defect.
- Use a feature request for a scoped product or extension proposal.
- Use GeoNode's community channels for questions that reproduce in an
  unmodified GeoNode interface and do not involve Mirante.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.
- Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns.

Before opening an issue, search existing reports and review the relevant guide
under `docs/`.

## Information to provide

- Mirante commit or release.
- GeoNode version.
- Browser and operating system.
- Host architecture, such as `linux/amd64` or `linux/arm64`, when containers
  are involved.
- Minimal reproduction steps.
- Sanitized errors and logs.
- Whether the problem also occurs directly in GeoNode.

Do not publish credentials, cookies, tokens, private datasets, personal data,
or production configuration.

## Compatibility

Only combinations listed in [Compatibility](docs/compatibility.md) are project
targets. Other combinations may work, but maintainers may ask for a minimal
reproduction on a supported combination before investigating.
